# 🔐 Лабораторные Работы по Дисциплине "Защита Информации"

Данный репозиторий содержит реализации ключевых криптографических алгоритмов, выполненные в рамках лабораторных работ по дисциплине "Защита Информации" (Криптография). Проект демонстрирует практическое применение классических, симметричных блочных, и асимметричных алгоритмов, а также отечественных стандартов Электронной Цифровой Подписи (ЭЦП).

---

## 📋 Содержание Лабораторных Работ

### 🧪 Лабораторная работа № 1: Классические Криптосистемы (Шифры Замены)

| Задание | Реализованный Алгоритм | Описание |
| :--- | :--- | :--- |
| **№ 1.3** | **Шифр "Двойной квадрат" Уитстона** | Реализация полиалфавитного шифра замены, использующего две ключевые матрицы $5 \times 5$ для повышения криптостойкости по сравнению с классическим "Квадратом Полибия". |

### 🔑 Лабораторная работа № 2: Алгоритмы Симметричного Блочного Шифрования (DES)

| Задание | Реализованный Алгоритм | Описание |
| :--- | :--- | :--- |
| **№ 2.3** | **DES в режиме CFB** (Cipher Feedback, Обратная связь по шифру) | Реализация классического стандарта DES, настроенного в режиме CFB. Данный режим позволяет использовать блочный шифр как потоковый, обеспечивая шифрование данных любой длины. |

### 🛡️ Лабораторная работа № 3: Алгоритмы Симметричного Блочного Шифрования (ГОСТ)

| Задание | Реализованный Алгоритм | Описание |
| :--- | :--- | :--- |
| **Основное** | **ГОСТ Р 34.12-2015 "Кузнечик"** | Реализация современного российского алгоритма блочного шифрования "Кузнечик" (Grasshopper) с длиной блока 128 бит и длиной ключа 256 бит. |

### ✍️ Лабораторная работа № 4: Асимметричное Шифрование и ЭЦП (RSA)

| Задание | Реализованный Алгоритм | Описание |
| :--- | :--- | :--- |
| **Основное** | **RSA (Шифрование и ЭЦП)** | Реализация алгоритма асимметричного шифрования RSA. Проект включает два ключевых модуля: 1) Шифрование/дешифрование данных. 2) **Формирование и проверка ЭЦП** на основе RSA. |

### 🇷🇺 Лабораторная работа № 5: Алгоритмы ЭЦП (ГОСТ)

| Задание | Реализованный Алгоритм | Описание |
| :--- | :--- | :--- |
| **Основное** | **ГОСТ Р 34.10-2018** (На эллиптических кривых) | Реализация полного процесса **формирования и проверки Электронной Цифровой Подписи**, основанного на операциях в группе точек эллиптической кривой. В реализации используется российская хеш-функция **ГОСТ Р 34.11-2018 ("Стрибог")**. |

Реализация алгоритма **ГОСТ Р 34.10-2018** была основана на открытом проекте [https://github.com/shomov/GOST-34.10-2018.git](https://github.com/shomov/GOST-34.10-2018.git) (автор — Михаил Шомов), за что выражается отдельная благодарность.

* **Графический Интерфейс (GUI):** Добавлен полноценный графический интерфейс пользователя для удобного выполнения всех криптографических операций (генерация ключей, подписание, верификация) без необходимости использования консоли.
* **Обновление Стэка:** Обновлены версии Java и системы сборки Gradle до актуальных стабильных релизов.

## 🚀 Как Запустить Проект

*Подробные инструкции по сборке и запуску будут зависеть от специфики проекта (наличие GUI, Main-класса).*

1.  Клонируйте репозиторий: `git clone https://ru.wikipedia.org/wiki/%D0%A0%D0%B5%D0%BF%D0%BE%D0%B7%D0%B8%D1%82%D0%BE%D1%80%D0%B8%D0%B9`
2.  Перейдите в корневую директорию проекта.
3.  Сборка проекта с помощью Gradle: `./gradlew build`
4.  Запуск основного приложения: `./gradlew run` (или через IDE).
